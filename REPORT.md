# Отчёт о работе с AI Coding Agents

Проект: Investing Demo (Python/Django). Задания 1–4 (включая все четыре варианта новой функциональности 4.1–4.4) выполнены двумя агентами. Каждый агент работал в отдельной копии проекта и в отдельной ветке; результаты одного агента другому не передавались.

## Условия и методика

| Параметр | Claude Code | GitHub Copilot |
|---|---|---|
| Интерфейс | Claude Code в терминале PowerShell | VS Code, чат Copilot, режим Agent |
| Модель | Opus 5.5 | Auto (в начале сессии GPT-6 Luna; в режиме Auto модель может меняться) |
| Тариф | подписка Claude Pro (платная) | Copilot Free |
| Версия | Claude Code 2.1.312 | — |
| Папка / ветка | `claude-run` / `agent/claude` | `copilot-run` / `agent/copilot` |
| Начало работы | 28.10.2026 | 26.10.2026 |

- ОС: Windows 11; Python 3.13; Docker Desktop 29.9.
- Источник рыночных данных: публичное API Мосбиржи ISS. Токена T-Invest API нет, поэтому реальные запросы к T-Invest не выполнялись ни одним агентом.
- Оба агента получили одинаковые промпты, слово в слово (Приложение A). Все уточнения сверх основного промпта фиксировались в журнале.
- Проверка результатов велась по одинаковым чек-листам (запуск приложения, тесты, просмотр `ANALYSIS.md`, проверка БД через psql, ручные проверки в браузере).
- «Сообщение агенту» = основной промпт задания или уточнение. «Время работы агента» взято из журналов в формате мм:сс; «всего» — время на задание вместе с моей проверкой, по записям итераций.

**Отклонение от критериев выбора агента.** Claude Code требует платной подписки (Pro), что не соответствует критерию «Стоимость: бесплатно или Free Tier без привязки карты». Claude Code был выбран как замена OpenCode CLI, у которого исчерпался бесплатный лимит (см. следующий раздел).

## Первоначально выбранный агент: OpenCode CLI

Первым агентом был выбран OpenCode CLI с бесплатной моделью GLM-5.3-Flash Free. Работа с ним была остановлена до выполнения задания 1:

- После первого сообщения с описанием окружения (без задания) агент сам начал модернизацию: поднял контейнеры Docker и стал устанавливать новые версии зависимостей в `.venv`. Запуск был прерван, рабочая копия возвращена в исходное состояние (`docker compose down -v`, `git restore`, `git clean`, удаление `.venv`).
- После нескольких сообщений бесплатный дневной лимит OpenCode был исчерпан («You've used today's free messages. They reset at 03:00 · 27.10.2026»). Попытка продолжить на другой бесплатной модели (DeepSeek V4.1 Flash Free) упёрлась в тот же лимит.
- Ветка `agent/opencode` в форке осталась от этого запуска и результатов заданий не содержит.

Вывод: бесплатный лимит OpenCode не позволил выполнить задание, а агент начал изменять проект без явной команды. После этого в описание окружения была добавлена фраза «Пока ничего не запускай, не устанавливай и не изменяй».

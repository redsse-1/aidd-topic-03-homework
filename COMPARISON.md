# Сравнительный анализ AI Coding Agents

Агенты: **Claude Code** (терминал, модель Opus 5.5, подписка Claude Pro) и **GitHub Copilot Free** в VS Code, режим Agent (модель Auto, в начале сессии GPT-6 Luna).
Выводы опираются на результаты заданий 1–4 и журналы работы. Подробности по каждому агенту приведены в `REPORT.md`.

> Методика. Оба агента получили одинаковые промпты и работали в отдельных копиях проекта (ветки `agent/claude` и `agent/copilot`). Время работы агента взято из журналов (мм:сс), «всего» включает мою проверку. Первоначально вместо Claude Code был выбран OpenCode CLI, но его бесплатный лимит исчерпался до выполнения задания 1 (см. `REPORT.md`).

## Выводы

1. **Где каждый агент показал себя лучше.** Claude Code лучше справился с заданиями 3–4 по объёму и самопроверке: 242 теста против 56, полная загрузка истории (255 акций против одной SBER), проверки параллельного доступа в 4.3 и 4.4, независимые пересчёты в 4.2 и 4.4; он же потратил меньше времени (66:36 против 73:02 работы агента, задание 3: 25 мин против 90) и меньше уточнений (3 против 5). Copilot лучше справился с заданием 2: не записал анонимную запись через API как требование и сам указал конфликт с тестами, тогда как Claude Code записал это поведение как FR-22 и дописал про тесты после подсказки. Copilot также тщательнее сверил реальные цены с сайтом MOEX и нашёл ошибку выбора поля ISS.
2. **Для каких задач целесообразно использовать Claude Code:** многошаговая модернизация и крупные функции, где нужны проверки корректности (параллельный доступ, расчёты) и много тестов. При этом результат нужно проверять визуально (пример — графики «в один пиксель»), а большой объём сгенерированного кода требует времени на ревью. Ограничение — платная подписка.
3. **Для каких задач целесообразно использовать Copilot:** задачи средней сложности внутри VS Code, анализ кода и требования, функции с небольшим объёмом, когда важен бесплатный тариф. Нужно контролировать запущенные процессы и операции git, а также учитывать, что в режиме Auto модель может меняться.
4. **Общий вывод.** Оба агента выполнили все задания 1–4, приложение у обоих запускается на данных Мосбиржи без токена T-Invest. Различия — в глубине реализации и самопроверки (сильнее у Claude Code), в аккуратности классификации требований и сверки данных (сильнее у Copilot) и в стоимости (Copilot бесплатен). Ограничения сравнения: один прогон на агента, разные модели (у Copilot режим Auto), время в журналах фиксировалось вручную.
